# MAG_MMC5983MA
<img width="500" height="500" alt="{760F2E21-1545-4E8E-9743-7433C1C3C1F7}" src="https://github.com/user-attachments/assets/61834d0a-5f56-4219-bbe5-ead33bdf11e4" />

The MAG-MINI is a compact, high-precision 3-axis magnetometer module based on the MMC5983MA sensor from Memsic. This device is designed to measure magnetic field strength in three dimensions with high resolution and low noise.

## Board Function Description
- Sensor Interface: The module communicates via the I²C interface (SDA, SCL) and can be easily interfaced with microcontrollers.
- Power Supply: Operates from a 5 V input, regulated down to the required 3.3 V for the sensor and logic circuitry.
